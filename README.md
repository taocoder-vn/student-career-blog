# Chạm — blog dành cho sinh viên

Website tĩnh, không cần cài đặt hay build. index.html là trang chính; giao diện được nhúng trong file để GitHub Pages không phụ thuộc vào CSS bên ngoài.

## Bật GitHub Pages

1. Đẩy nhánh main lên GitHub.
2. Mở Settings → Pages của repository.
3. Trong Build and deployment → Source, chọn GitHub Actions.
4. Mỗi lần cập nhật nhánh main, workflow sẽ tự xuất bản website. Có thể theo dõi tiến trình ở tab Actions.

Repository hiện tại dự kiến có địa chỉ website https://taocoder-vn.github.io/student-career-blog/ sau khi Pages được bật và workflow chạy thành công.

## Chạy trên máy

Mở index.html trực tiếp bằng trình duyệt. websinhvien.html là bản độc lập có cùng giao diện.
